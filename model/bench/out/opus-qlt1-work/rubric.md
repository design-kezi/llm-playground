# Opus(조정 세션) 블라인드 묶음 판정. 1~5점: character(설정·말투·세계 유지, 메타 발언은 낮게) · context(직전 말·상황에 맞음, 모순 없음) · engagement(대화를 자연스럽게 이어 감, 짧은 말에 반응, 새 주제를 받음) · user_agency(사용자의 감정·행동·생각을 단정하거나 대신 정하지 않음; 요청받은 제안은 괜찮고 단정만 감점) · overall(계속 대화하고 싶은 쪽). 길이는 기준 아님.
