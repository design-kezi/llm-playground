사전 등록: `docs/50-decision-log.md` "판단 모델 추론 끔/켬 비교 — 사전 등록". 순위는 매기지 않는다. 표를 보고 사용자가 고른다.

## 1. 설정
- 문항: `model/judge/reason/questions.json`, 한국어 10문항(저장 3, 꺼내기 3, 수정 대상 4). 조정 세션이 작성했고 **사람이 검수하지 않았다.**
- 질문 문장·출력 형식은 판단 v2와 같다. 과제마다 한 번에 묶어 호출해서 회차당 3호출이다.
- 끔 = v2와 같은 설정. 켬 = 낮은 강도(low)로 켬. 모델별 실제 값은 `model/pricing.json`의 `reasoning.on`에 있다.
- 조건마다 5회 반복했다. max_tokens 4,000, 운영 설정의 시간 초과(60초)와 재시도(2회)를 그대로 썼다.
- 대상은 10개 모델이다.
  - gpt-4.1-nano는 OpenAI가 404(지원 종료)를 내서 뺐다.
  - Llama 3.1은 추론 기능이 없어 끔만 쟀다.

## 3. 라벨 의심 문항: T4 (결과를 본 뒤 발견, 라벨은 고치지 않음)
- 문항: "커피 끊은 거 취소한다고 했었잖아. 근데 그것도 취소야. 결국 지금도 안 마셔." 항목은 [0 커피를 끊었음, 1 아침마다 조깅함]이고 정답은 none이다.
- 95회 응답 중 80회가 0, 12회가 none, 3회가 1이었다.
- 질문이 "change, update, or cancel"이라서 "같은 상태를 다시 확인한 것도 0번 항목에 대한 갱신"으로 읽을 여지가 있다. 그래서 내가 붙인 none 정답이 질문 정의와 어긋날 수 있다. 기억 레이어에서 0을 고르면 같은 값으로 UPDATE가 되어 실제 피해는 작다.
- 참고로 T4를 뺀 9문항 점수다(사후 계산, 사전 등록 지표 아님).

## 4. 관찰 (데이터 그대로)
- 켬으로 점수가 오른 모델: deepseek(+1.6), gemma-26B(+0.6), Qwen(+1.6), gpt-5-nano(+3.0). 오른 부분 중 deepseek과 gemma-26B는 상당 부분이 T4에서 나왔다.
- 같은 모델: gemma-31B, gemini-3.5, gpt-6-luna. gemini-3.5는 LOW로 켜도 추론 토큰이 0이라 실제로 생각하지 않았다. 비용도 거의 같다(1.1×).
- 내려간 모델: Haiku(−0.2, S2를 0/5로 틀리고 T3도 2/5로 떨어짐), gemini-3.1(−0.2).
- 켬은 비용이 2~14배이고, gemma와 Qwen은 지연이 평균 12~23초다.
- 추론 토큰 집계: gemma-4-26B와 Qwen은 출력 토큰이 늘었는데(21→1,006, 26→520) 추론 토큰이 0으로 나온다. DeepInfra가 이 모델들의 생각 토큰을 따로 보고하지 않는 것으로 보인다. 과금은 출력 토큰 기준이라 비용 계산은 맞다. Haiku도 생각 토큰이 출력 토큰에 합쳐져 나온다.

## 6. 한계
- 10문항이다. 한 문항이 1점이라 1점 차이는 문항 하나 차이다. 모델 사이 차이를 통계적으로 확인하지 않았다.
- 같은 10문항을 5번 반복한 것이라, 출력이 거의 고정된 모델은 회차 사이에 차이가 없다(최소=최대).
- 한국어만 했다. 문항과 정답은 사람이 검수하지 않았고, T4 라벨은 의심 문항이다(§3).
- 켬은 낮은 강도(low)만 쟀다. medium·high는 재지 않았다.
- 실제 기억 추출 흐름(B단계)에서 켬은 재지 않았다.
