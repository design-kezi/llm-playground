# 오류·버그 합동 점검 (2026-10-23)

## C. 다시 측정하기 전 통과 조건

1. 세 세션 단위 테스트 통과.
2. `node model/bench/audit.mjs` 검산 불일치 0, 토큰 추정 0건, 벤치 run.json 의 `ledger_check.match = true`.
3. run.json 에 빌드·설정 기록(A11), 사전 호출 통과(A12).
4. 기억 점수는 전체 문항 기준 + AI 판정(두 모델 교차) + 불일치 문항 사람 확인. 미채점은 실패 가능으로 표시.
