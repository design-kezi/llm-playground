- 작성: 채팅앱 세션, 2026-11-01.
- 표기: `[ ]` 아직 확인 전. 탭 대조 결과는 맨 아래 "대조 결과"에 적는다.
- 평가 관점 5개(비용 효율·대화 경험·장기 기억·근거의 신뢰성·판단력)는 각 항목 끝 괄호에 표시했다.

### 사용자 결정 (2026-11-01): 서버 안 임베딩의 비용 처리
- 실측하지 않고 전제로 둔다.
- **1원(AI 비용) 안**: 임베딩에 쓰는 CPU 사용량만. 턴당 임베딩 CPU 시간(가정) × vCPU 1초 단가(리포트 서버 가정 Lightsail 2 vCPU·월 $24 ≈ 33,600원 → ≈ 0.0065원/vCPU초). 가정값 턴당 100ms → 약 0.0007원/턴. 리포트에는 [추정]·가정으로 표기.
- **1원 밖(서버 운영비)**: 모델의 메모리 상주.
- 근거 문구(과제): "자체 호스팅 모델을 사용한다면 추론 인프라 비용과 사용량 가정을 제시 … 보유 장비라는 이유로 추론 비용을 0원으로 계산하지 않습니다."
- 적용 시점: 기억 레이어가 서버 안 임베딩으로 바뀐 뒤(지금은 gemini-embedding-001 API, 장부 실측으로 이미 1원 안에 포함).
- 추가 결정(같은 날): 이 값(≈0.0007원/턴 [추정])은 리포트에 **언급하되 매우 작아 본 표 평균에서는 제외**한다. 리포트 문구에 계산식·가정, 제외 이유("작아서", 보유 장비라서가 아님), 포함 시 평균 값(1원 판정 불변)을 함께 적는다.
