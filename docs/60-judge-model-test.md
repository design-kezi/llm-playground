## 6. 확인하지 않은 것 (한계)
- B단계는 **한국어만** 했다. 다국어로 실제 추출 흐름을 돌렸을 때의 성능은 재지 않았다.
- B단계 입력은 Haiku가 만든 캐릭터 응답 녹화본이다. 대화 모델이 바뀌면 추출 결과도 달라질 수 있다.
- A는 실제 호출 형식이 아닌 대리 과제이고, 질문 정의와 라벨이 어긋난 문항이 있다(§2.4).
- 손으로 쓴 문항, 번역, B단계 정답 키워드는 사람이 검수하지 않았다. B단계는 키워드 대조라 바꿔 말한 표현을 놓칠 수 있다.
- 반복은 3회다. 모델 사이 차이가 작은 경우(예: A 4·5·6위)는 통계적으로 구분된다고 확인하지 않았다.
- 지연 시간은 기록만 했고(`report.md`), 판단 기준에는 넣지 않았다.
- 모든 모델을 **추론 끔**(`MODEL_REASONING=off`)으로 쟀다. 추론 토큰은 gpt-5-nano(minimal로 대체, 900호출 합계 800토큰)만 0이 아니다. 추론을 켰을 때의 정확도와 비용은 재지 않았다. (2026-10-24 사후 추가)
- 모델마다 **제공사 하나**로만 쟀다(예: gemma·Qwen·Llama는 DeepInfra). 같은 모델을 다른 제공사에서 돌렸을 때의 차이는 재지 않았다. (2026-10-24 사후 추가)
- 판단 모델이 캐릭터 응답 품질에 주는 영향은 이 테스트 범위 밖이다(다음 단계: 대화 모델 비교).
